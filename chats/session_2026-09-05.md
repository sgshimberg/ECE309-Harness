## Turn 2 — Assistant

Logged this as the RUNNING and EXIT state definitions in
`vibe_coding_log.md`. Captured details:

- Buffer: `char buffer[256]`, read via `fgets(buffer, 256, stdin)`.
- Newline stripping required after every `fgets` call.
- `exit` check happens via `strcmp` immediately after stripping, before any
  storage call — "exit" itself must never enter history.
- Non-exit path: `Storage_Context(buffer, USER)` → `Model(buffer)` →
  `Storage_Context(response, MODEL)` → print response → loop.
- `Storage` is a static/global 2D array `Storage[][256]`, indexed by
  `Storage_Idx` — no heap allocation, so `Exit` state clears it in place
  (no `free()`) rather than freeing it.
- Exit state: clear `Storage`, set context-management state to `END`,
  print "Goodbye.", call `exit(0)`.
